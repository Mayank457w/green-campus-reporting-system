# Green Campus Reporting System

CHE110 Environmental Studies, CA1 (Topic 14), Section K4P26CG.

**Team:** Mayank Singh (12619062, RK4P26CGB41), Suhani Kumari (12619526, RK4P26CGB42), Hemant Kumar (12619657, RK4P26CGB43).

## Problem
Small environmental problems on campus (leaking taps, overflowing bins, electricity waste, littering) often go unreported.

## Solution
A web app where students report problems, and staff track each one until it is resolved.

## Features
- Report form: type, location, severity, description, optional photo
- Chart of reports by type
- Admin dashboard with totals (reported, in progress, resolved)
- Filters by type, severity and status
- Change status, delete a report, export all reports to CSV
- Data saved in the browser (localStorage)

## Tech stack
HTML, CSS, JavaScript. No frameworks.

## Files
- `index.html`: page structure
- `style.css`: design
- `script.js`: logic

## How to run
Download the folder and open `index.html` in a browser.

## Limitations and future work
Reports are stored only in the browser of one device. Future versions could add an online database, admin login and email alerts.
